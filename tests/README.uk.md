# Тести

<p><a href="README.md">English</a> · <b>Українська</b></p>

Стандартна бібліотека Python, без pytest і зайвих залежностей.

```bash
cd tests
python -m unittest discover -s . -p "test_*.py" -v
```

Те саме автоматично робить CI на кожен push.

## Що перевіряється

| Файл | Про що |
|---|---|
| `test_links.py` | детекція силок і платформ, зрізання `?igsh=`, All-in не перехоплює інші сервіси |
| `test_settings.py` | живі параметри тримають межі, сходинки якості не бувають порожні, доступи й міграція старої бази |
| `test_lite.py` | LITE не пише на диск, працює лише в групах, `ALLOWED_CHATS`, і головне — не ламає повний режим |
| `test_i18n.py` | однакові ключі в `uk`/`en`, немає українських рядків повз словник, усі `data-i18n` перекладені |
| `test_sending.py` | назви постів ззовні не ламають повідомлення: розмітка вимкнена, у рядках не лишилось маркерів |
| `test_cookies.py` | короткоживучі TikTok-cookies вичищаються при завантаженні (один протухлий перетворює будь-який запит на 403), логін-ключі та інші сайти не страждають, файл лишається читабельним |
| `test_entrypoint.py` | самооновлення yt-dlp реально працює: для кожного каналу задокументований спосіб, жодних мертвих посилань, помилка не мовчить |
| `test_release.py` | workflow публікації збирає під amd64+arm64, перевіряє образ до релізу й не потребує ручних секретів; обидва стеки тягнуть опублікований образ |
| `test_deploy.py` | compose парситься без дублів, кожна змінна читається кодом, `.dockerignore` не ріже потрібне, у репозиторії немає секретів |

## Як писати нові

`helper.load_bot(**env)` імпортує `bot.py` у тимчасовій теці з чистим оточенням —
кожен виклик дає незалежний модуль зі своєю базою:

```python
from helper import load_bot

bot = load_bot(LITE=1, MAX_HEIGHT=1080)
bot.db_init()
bot.settings_load_sync()
```

Нічого не пишеться в теку проєкту, тести не залежать одне від одного
й від змінних оточення хоста.

## Перевірено на поломках

Кожну перевірку валідували навмисною поломкою того, що вона стереже —
щоб переконатись, що вона справді падає: прибрані `strip` в Instagram, All-in не останній у реєстрі, знятий
затиск меж у `tunable`, LITE із записом у базу, забутий англійський переклад,
українська літералом у відповіді, напис без `data-i18n`, дубльований ключ у compose,
зайва змінна, потрібний файл під `.dockerignore`.
